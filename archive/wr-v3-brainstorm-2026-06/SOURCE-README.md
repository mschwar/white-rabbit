# WR-v3 Lead Generation Notes

This folder contains six handwritten lead-generation brainstorm photos and one cleaned markdown transcription/expansion for each photo.

The notes describe an early lead-generation request model: user requests are broken into individual/title targets, business or industry targets, scope filters, public data sources, and example request templates.
